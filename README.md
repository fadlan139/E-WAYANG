# E-WAYANG
E-Wayang adalah program wayang kulit digital interaktif dengan tokoh Bima dan Arjuna yang dikendalikan lewat gerakan tangan menggunakan hand tracking MediaPipe. Berjalan langsung di browser tanpa instalasi dan ramah tablet, sehingga siapa pun bisa menjadi dalang dan ikut melestarikan budaya wayang Indonesia dengan cara yang modern.
