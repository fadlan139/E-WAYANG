═══════════════════════════════════════════════════════════════
                     E-WAYANG INSTALLATION GUIDE
═══════════════════════════════════════════════════════════════

Program ini membutuhkan:
✓ Python 3.10 atau lebih tinggi
✓ Webcam/Kamera
✓ Koneksi internet (untuk first-time dependency download)

═══════════════════════════════════════════════════════════════
LANGKAH 1: DOWNLOAD & SETUP
═══════════════════════════════════════════════════════════════

A. Jika belum clone repo:
   git clone https://github.com/fadlan139/E-WAYANG.git
   cd E-WAYANG

B. Setup virtual environment (recommended):
   python -m venv venv
   
   Windows:
   venv\Scripts\activate
   
   Linux/macOS:
   source venv/bin/activate

═══════════════════════════════════════════════════════════════
LANGKAH 2: INSTALL DEPENDENCIES
═══════════════════════════════════════════════════════════════

Pilih A ATAU B:

A. DENGAN PIP (Simpel):
   pip install -r requirements.txt

B. DENGAN CONDA (Recommended):
   conda env create -f environment.yml
   conda activate e-wayang

═══════════════════════════════════════════════════════════════
LANGKAH 3: JALANKAN PROGRAM
═══════════════════════════════════════════════════════════════

python main.py

Terminal akan menampilkan:
[CHECK] Semua audio, dialog, dan background ditemukan.

Jika berhasil, jendela aplikasi akan terbuka.

═══════════════════════════════════════════════════════════════
KONTROL
═══════════════════════════════════════════════════════════════

SPACE  = Lanjut dialog berikutnya (setelah voice selesai)
F11    = Toggle Fullscreen
P      = Mode Projector
ESC    = Keluar

═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

ERROR: ModuleNotFoundError: No module named 'pygame'
FIX:   pip install --force-reinstall -r requirements.txt

ERROR: Camera tidak terdeteksi
FIX:   - Buka config.json
       - Ubah "camera_index" dari 0 ke 1 (atau 2, 3, dst)
       - Restart program

ERROR: Audio tidak terdengar
FIX:   - Pastikan file MP3 ada di folder audio/
       - Cek volume sistem operasi
       - Cek file MP3 valid

ERROR: Program jalan lambat
FIX:   - Kurangi window size di config.json
       - Set "show_camera": false
       - Close program lain yang memberat

═══════════════════════════════════════════════════════════════
KONFIGURASI (Optional)
═══════════════════════════════════════════════════════════════

Edit file: config.json

window:
  width, height      = Ukuran jendela (default: 1280x720)
  camera_index       = Nomor kamera (0, 1, 2, dst)
  show_camera        = true/false - tampilkan feed kamera
  show_pov           = true/false - tampilkan POV puppet

puppet:
  target_height      = Tinggi wayang (pixels)
  left_start_x/y     = Posisi wayang kiri
  right_start_x/y    = Posisi wayang kanan
  smooth             = Smoothing gerakan (0.0-1.0)

rig:
  enabled            = true/false - aktifkan rigging
  arm_driver         = 'thumb' atau 'palm'
  rods               = true/false - tampilkan rod guides

BUTUH BANTUAN?
═══════════════════════════════════════════════════════════════

1. Lihat terminal output untuk error messages
2. Cek config.json apakah settings sudah benar
3. Pastikan semua files di folder audio/ sudah ada
4. Coba restart dengan virtual environment baru
5. Cek GitHub issues atau forum
